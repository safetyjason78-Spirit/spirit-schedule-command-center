# Spirit Schedule Command Center

A private, browser-based scheduling assistant for the Spirit Halloween stores in Arnold and Crystal City, Missouri.

## Current features

- Separate store selector, hours, employees, availability, and schedules for both locations
- Employee job titles: Store Associate, Assistant Manager, and Store Manager
- Availability-driven automatic schedule generation
- Two manager-qualified employees required at opening and two at closing
- Editable generated shifts for quick corrections
- Weekly labor-hour totals and manager-coverage warnings
- Device-local saving with no external database
- Print-friendly schedule for entry into Spirit Halloween's official scheduling system

## Run locally

Open `index.html` in a modern browser. The application is self-contained and does not require installation or a build step.

## Data and privacy

Employee and schedule information is stored only in the browser's local storage on the device being used. It is not committed to this repository.
